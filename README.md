# 8 Ball Pool 3D

**Браузерный 3D-бильярд с физикой шаров, правилами американского пула-8 и компьютерным соперником.**

Проект разрабатывается на **TypeScript, Three.js и Rapier** с использованием Vite. Основная цель — создать доступную браузерную игру с понятным управлением, правдоподобным поведением шаров и возможностью играть против компьютера.

**Статус проекта:** в активной разработке (ранний MVP).

**Целевая платформа:** ПК, веб-браузеры. В перспективе — публикация на Яндекс Играх.

---

## Об игре

8 Ball Pool 3D — трёхмерный симулятор американского пула-8, в котором игрок соревнуется с компьютерным соперником.

Игровой процесс построен вокруг физического взаимодействия шаров: столкновений, отражений от бортов, замедления движения и попадания в лузы.

Игра использует собственную систему правил, отслеживающую первый контакт битка, забитые шары, нарушения, переходы хода и определение победителя.

Визуальная часть реализована на Three.js, а физическая симуляция — на Rapier.

## Возможности

### Игровой процесс

- Полноценный трёхмерный бильярдный стол с шестью лузами.
- 16 шаров: биток и 15 пронумерованных прицельных шаров.
- Сплошные и полосатые шары с классической цветовой схемой.
- Случайная расстановка пирамиды с соблюдением основных ограничений пула-8.
- Прицеливание, регулировка силы и анимация удара кием.
- Обзор стола с управляемой камерой.
- Размещение битка после нарушений.
- Определение победителя и отображение результата партии.

### Физическая симуляция

- Столкновения шаров между собой.
- Отражения от бортов.
- Постепенное замедление шаров.
- Определение попаданий в лузы.
- Обработка выхода шаров за пределы стола.
- Физическое исполнение ударов игрока и компьютерного соперника.

Физика ориентирована на баланс между правдоподобием и удобством аркадного игрового процесса.

### Компьютерный соперник

Реализован базовый игровой бот, использующий геометрическое планирование ударов.

Бот умеет:

- Выбирать допустимые прицельные шары.
- Рассчитывать направление удара с помощью метода *ghost ball*.
- Проверять прямолинейные траектории на наличие препятствий.
- Оценивать примерную сложность удара.
- Подбирать направление и силу.
- Самостоятельно размещать биток.
- Выполнять разбой и последовательные игровые ходы.

Алгоритм не использует машинное обучение. Решения принимаются на основе геометрии игрового поля и текущего состояния партии.

### Интерфейс

- Главное меню.
- Информация о правилах и управлении.
- Игровой HUD с группами и оставшимися шарами.
- Индикация текущего игрока.
- Меню паузы.
- Перезапуск партии без обновления страницы.
- Экран победы или поражения с объяснением результата.
- Раздел с дорожной картой разработки.

## Правила игры

В основе игры лежат правила американского пула-8.

В партии участвуют два игрока:

- Первый играет за человека.
- Второй управляется компьютером.

После разбоя игрокам назначаются группы:

- **Сплошные:** шары №1–7.
- **Полосатые:** шары №9–15.

Цель — убрать со стола все шары своей группы, а затем законно забить чёрный шар №8.

Система правил учитывает:

- Первое касание битка с прицельным шаром.
- Попадания шаров в лузы.
- Контакты шаров с бортами.
- Попадание битка в лузу.
- Нарушения при выборе первого шара.
- Назначение групп.
- Передачу хода.
- Право размещения битка после фола.
- Условия победы и поражения.

**Примечание:** текущая версия использует упрощённую реализацию некоторых правил. Заказ конкретного шара и лузы не требуется. После разбоя стол остаётся открытым, а отдельные ситуации при разбое обрабатываются по правилам MVP.

Полное соответствие официальному регламенту не заявляется.

## Управление

Игра ориентирована на использование клавиатуры и мыши.

| Действие | Управление |
|---|---|
| Осмотр стола | Мышь |
| Перейти к прицеливанию | `A` |
| Изменить направление удара | Удерживать ЛКМ и двигать мышь |
| Увеличить силу удара | `↑` |
| Уменьшить силу удара | `↓` |
| Выполнить удар | `Space` |
| Переместить биток при размещении | Мышь |
| Подтвердить положение битка | ЛКМ |
| Пауза / продолжение | `Esc` |

Во время хода компьютерного соперника управление ударом и размещением битка блокируется.

## Запуск проекта

Для локального запуска необходимы Node.js и npm.

**1. Клонировать репозиторий**

```bash
git clone https://github.com/KirillReyzi/pool-3d.git
cd pool-3d
```

**2. Установить зависимости**

```bash
npm install
```

**3. Запустить сервер разработки**

```bash
npm run dev
```

После запуска Vite открой адрес, указанный в терминале (обычно `http://localhost:5173/`).

### Сборка проекта

```bash
npm run build
```

Собранные файлы будут находиться в директории `dist/`.

### Тестирование

```bash
npm run test
```

Дополнительная проверка типов TypeScript:

```bash
npx tsc --noEmit
```

## Архитектура

Код разделён на независимые функциональные модули.

| Модуль | Ответственность |
|---|---|
| `Game` | Основной игровой цикл и взаимодействие подсистем |
| `GameRules` | Проверка правил, фолов и условий победы |
| `MatchController` | Управление состоянием матча и очередностью игроков |
| `PhysicsWorld` | Физические тела, движение и столкновения |
| `ShotPlanner` | Геометрическое планирование ударов бота |
| `BotController` | Управление действиями компьютерного соперника |
| `CueController` | Прицеливание и анимация кия |
| `Rack` | Генерация допустимой расстановки шаров |
| `GameHUD` | Отображение состояния партии |
| `MainMenu` | Главное меню |
| `PauseMenu` | Управление паузой |
| `ResultScreen` | Отображение результата матча |

Игровые правила отделены от графики и физической симуляции. Такой подход позволяет тестировать критическую логику без запуска браузера и 3D-сцены.

## Тестирование

В проекте используются автоматизированные тесты Vitest для проверки игровой логики.

Основные направления тестирования:

- Обработка фолов и распределение групп.
- Определение победителя.
- Управление состоянием матча.
- Планирование ударов компьютерного соперника.
- Генерация допустимой расстановки шаров.

Тестовое покрытие будет расширяться по мере развития проекта.

## Текущие ограничения

Проект находится на ранней стадии разработки.

На данный момент:

- Игра рассчитана на ПК.
- Доступен режим против компьютерного соперника.
- Некоторые правила пула-8 упрощены.
- Бот использует базовый геометрический алгоритм.
- Физика имеет аркадные допущения.
- Возможны ошибки и нестандартные игровые ситуации.
- Публичный релиз ещё не состоялся.

Создать самостоятельную браузерную игру, которая сочетает доступное управление, правдоподобную физику и достаточно интересного компьютерного соперника.

Первый этап разработки ориентирован на выпуск стабильной однопользовательской версии для ПК с последующей публикацией на Яндекс Играх.
